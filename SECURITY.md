# Security

Allostat decides if risky actions may start. A bug that gives a grant
where it should refuse is a security problem.

## Reporting

Please do not open a public issue. Report in private at
https://github.com/JPaiv/Allostat/security/advisories/new

Include the smallest input that shows the problem.

## Supported versions

There is no release yet. Only the `main` branch gets fixes.
